# Criterio de escritura del informe

El archivo [informe.md](informe.md) es la base para preparar el informe PDF.

No agregar slop de IA: relleno, frases genéricas, repeticiones ni explicaciones que no aporten información sobre el trabajo realizado.

Completar cada sección con contenido resumido, concreto y fiel a lo implementado y probado. Transmitir con pocas palabras qué se hizo, por qué y con qué resultado. No presentar tareas pendientes como realizadas ni inventar resultados.

Mantener el texto fácil de revisar y convertir luego en `informe.pdf`.
